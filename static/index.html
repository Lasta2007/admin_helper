Яндекс 360 API настройки (синхронизация с ALD Pro)

Запросы Directory API (списки и создание подразделений/сотрудников, /directory/v1/org/{orgId}/...) приложение всегда отправляет на https://api360.yandex.net — этот метод поддерживается только там (см. документацию). На cloud-api.yandex.net такие пути возвращают HTTP 404 NotFoundError.
Токен получается по ссылке https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID> для приложения с правами directory:read_users, directory:read_departments. Передается в заголовке Authorization: OAuth <токен>. Методы DepartmentService_Create / UserService_Create доступны только на основном хосте https://api360.yandex.net (приложение отправляет туда все запросы Directory API) и только при использовании токена корпоративного приложения Яндекс 360 с правами directory:write_departments и directory:write_users. Если токен возвращает HTTP 405 MethodNotAllowedError — укажите здесь отдельный токен с правами записи. Оставьте пустым, чтобы использовать основной токен.
